# Java Lab 7 - Doubly Linked List

A hands-on Java exercise about nodes with two links: `next` and `prev`.

## Skills practiced
- Create and connect doubly linked nodes
- Insert and delete at different positions
- Search recursively
- Display the list forwards or backwards
- Reverse the order of a list

## Files and running
Use package `lab5` in Eclipse and import `Node.java`, `DoubleLinked.java` and `main.java`. Run `main.java`.

## Important test cases
Empty list, one node, deleting the head or tail, searching for a missing key and reversing the list. Pointer updates in this learning-stage version require review before reuse.
